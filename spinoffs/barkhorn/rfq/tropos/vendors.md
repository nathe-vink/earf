# Candidate vendors, the first Tropos pair (public sources only, checked 2026-10-30)

This is a shortlist for each kind of work in the requests: Bay Area first, then the rest of the US. It comes from each
vendor's own site or public listing. **Nobody here has been contacted**, no form was filled and no account opened.

Some sites refused to load: TAP Plastics, Interstate Plastics and Profile Plastics (403); Freetech, Acrylonics and
Kreative Acrylics (503). Their details come from search snippets or directory listings and are marked "unconfirmed".
Check each contact route on the vendor's own site before sending.

Two points apply to the whole list:

- **Cement.** No Bay Area shop found says publicly that it makes two-part polymerising joints (Weld-On 40 or ACRIFIX
  2R 0190). E&F Plastics, for one, says "solvent bonding". The cabinet's joints are polymerising (round 35). Ask each
  shop directly.
- **Custom colours.** No current public minimum exists for a custom-colour cast sheet. The only explicit figure is old.
  Plastiglas/Chemcast's 2006 brochure ([PDF](https://courses.cit.cornell.edu/mae2250/Emerson/Chemcast_Acrylic_brochure.pdf))
  asked about 2,500 lb to develop a custom colour, charged in full if an approved match was cancelled, and set a new
  minimum batch for each reorder. Expect pallet-scale minimums. For the prototype pair, ask for the nearest stock
  tinted cast colour as well as a custom match. Laird Plastics, a distributor, says custom matching goes through its
  local rep, to a Pantone or an existing colour ([Laird](https://lairdplastics.com/services/)).
