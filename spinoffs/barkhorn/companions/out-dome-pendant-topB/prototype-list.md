# Hemisphere: the prototype list (V12-14, 25 Nov 2026)

The first-article and prototype tests the drawings and NOTES send here. Copied into each Hemisphere package as
prototype-list.md by hemi_wiring.py. Each line: the test, how, what passes, and what it answers. None of these has been run.
